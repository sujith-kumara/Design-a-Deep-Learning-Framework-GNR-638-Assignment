To run the project from here, you can use these shortcuts:

**1. Run Dataset 1 Training:**
```bash
./Assignment_1/cpp_implementation/scripts/run_data_1.sh
```

**2. Run Dataset 2 Training:**
```bash
./Assignment_1/cpp_implementation/scripts/run_data_2.sh
```

**3. Run Interactive Setup:**
```bash
./Assignment_1/cpp_implementation/setup_and_run.sh
```
